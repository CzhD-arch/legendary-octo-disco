# legendary-octo-disco

A tiny browser game where GPT model personas chat and play a fast-paced Mafia simulation.

## Run

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- 6 model players selected from popular GPT-family names.
- Automatic day/night Mafia rounds.
- Live chat banter between models.
- Built-in procedural sound cues with mute + volume control.
